Shreyas Manandhar:
I implemented a general tree for the department hierarchy. Each node of the tree keeps a pointer to its parent and a vector of children. It makes it efficient because the depth and the parent can be found without explicit search from the root. I wrote DepartmentTree.h/.cpp which had the Departments.txt loader. I also coded validation rules which define that root's parent must be NONE, name should be unique and case-insensitive, NONE cannot be used as a name. I implemented addition of a department, case-insensitive search, hierarchy display, and preorder traversal using recursion for traversals. The deleting of tree nodes also used recursion. I tested my portion as well as the whole program in a CELL machine.
